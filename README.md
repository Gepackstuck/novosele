# preview

Статические одностраничники для GitHub Pages. Каждый раздел лежит в своей папке и открывается по адресу `https://<ваш-логин>.github.io/preview/<раздел>/`.

Корневой `index.html` — список разделов.

## Добавить раздел
1. Создайте папку с именем раздела и положите в неё `index.html`.
2. Добавьте ссылку на раздел в корневой `index.html`.
