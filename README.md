# Новоселье 22.11.2006 — страница с анкетой

Статическая страница (GitHub Pages) + Google Таблица как «база» (без серверов, ботов и своей БД).

## 1. Выложить страницу на GitHub Pages
1. Создайте на GitHub публичный репозиторий, например `novosele`.
2. Загрузите в него `index.html` (основной, окно XP; `index-anketa.html` — запасной вариант с тетрадным листом) (кнопка *Add file → Upload files*).
3. *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save*.
4. Через минуту страница откроется по адресу `https://<ваш-логин>.github.io/novosele/`.

## 2. Создать таблицу
1. Создайте новую Google Таблицу.
2. *Расширения → Apps Script*, удалите всё, вставьте содержимое `Code.gs`, сохраните.

## 3. Опубликовать приём анкет
1. *Начать развёртывание → Новое развёртывание → Тип: Веб-приложение*.
2. *Выполнять от имени: Я*; *Доступ: Все*. Нажмите *Развернуть*, разрешите доступ.
3. Скопируйте адрес веб-приложения (вида `https://script.google.com/macros/s/.../exec`).
4. В `index.html` вставьте его в `CONFIG.endpoint` и, когда будете готовы, подставьте реальный адрес в `CONFIG.address`. Сохраните файл в репозитории.

Каждая анкета появится новой строкой в таблице. Таблицу можно скачать в CSV или положить в репозиторий вручную.

## Важно
- Страница публичная: адрес, который вы впишете в `CONFIG.address`, увидят все, у кого есть ссылка. Если не хотите, оставьте «адрес пришлю лично» и сообщайте его тем, кто ответил.
- В репозиторий нельзя безопасно писать прямо со страницы: для этого нужен токен, а в публичном коде он станет доступен всем.
